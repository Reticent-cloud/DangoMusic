# Dango Music 1.6.0 更新日志

发布日期：2026-10-28。相对 1.5.0 的变化。

## 新增

**多音源**
- 网易云 / QQ 音乐 / 酷狗三个音源，在侧栏底部账号栏切换，自动保存选择；切换浏览的音源不打断正在播放的歌。
- QQ 音乐、酷狗都在游戏内用对应 App 扫码登录，保存登录状态、昵称和头像；不需要另装 Node.js、Python 或第三方音乐 API 服务。
- QQ 音乐：我喜欢、自建及收藏歌单、首页推荐、排行榜、完整歌单分页、搜索、QRC 逐字歌词。
- 酷狗：我喜欢 / 默认收藏、自建及收藏歌单、新歌首发、排行榜、完整歌单分页、搜索、KRC 逐字歌词。
- 新音源复用原有的播放队列、HUD、3D 歌词和全部歌词效果；没有逐字歌词时回退普通歌词。

**主菜单**
- 在原版主菜单按 Open key（默认 M）也能打开播放器，用原版动态全景做玻璃背景，再按一次淡出关闭。
- 播放时主菜单左上角显示 Now playing（小封面、歌名、歌手、音柱）。

**一起听歌**
- 支持三个音源（房间协议 3），每位成员用自己的账号取歌。
- 国内网络连不上 Firebase 时，默认经 Cloudflare 中转连接，无需代理软件；中转不可用时自动改为直连。
- 新增“连接方式”：跟随系统代理（默认）/ 直连 / 手动填代理地址，只用于一起听歌。
- 同步瘦身：推送下来的变化直接合并，不再反复读取整个房间，两人房间每分钟的请求从约 30 次降到约 6 次。
- 连不上时按原因提示（登录服务 / 数据库 / 代理 / 中转），并缩短等待时间。

**其他**
- 新版本提醒：每次启动查一次 GitHub 上的最新正式版，有更新时灵动岛提醒一次，设置页顶部可复制对应游戏版本的下载链接。只提醒，不自动下载；可在设置 → 更新里关闭。
- 界面动画：音源菜单液态弹出、搜索框聚焦、设置按钮回弹；设置页标签切换（选中块滑动、内容左右滑入滑出）、开关滑动、发光颜色和语言选择动画，关掉某项后子选项渐变变暗；播放栏按钮悬停 / 点击回弹，播放与暂停图标过渡，随机和单曲循环颜色渐变。
- 打开歌单时显示加载进度条（已加载多少首 / 共多少首），不再只有一行 Loading。
- 初始音量改为 20%（只影响第一次安装）。

## 改进与修复

- 修复 QQ 音乐扫码确认页白屏、手机确认成功但游戏提示失败的问题，以及登录后缺少昵称和头像的问题。
- 改进 QQ 音乐取歌：优先使用与 App 登录匹配的接口，补查缺失的媒体信息，尝试多个音质。
- 区分登录失效、网络错误和没有播放权限，不再把无权限一律报成登录过期。
- 各平台登录凭证互相隔离，不会发给其他平台、音频服务器或一起听歌的其他成员；日志不记录凭证和完整播放地址。
- 修复主菜单播放器玻璃背景变成粉绿色、全景朝向和亮度在开关时跳变，以及 1.20.1 / 1.21.1 全景绘制错误。
- 修复 26.2 / 26.3 开启 3D 歌词后其他模组（如 Modern UI）的文字被染红（issue #12）。

## 兼容与注意

- 一起听歌：1.6.0 新建的房间需要所有成员都使用 1.6.0（或 beta.10 以后的测试版）；1.6.0 仍可加入旧版本创建的房间。数据库规则不变。
- 登录不等于能播放：会员、地区和平台验证仍会影响能否播放。
- QQ / 酷狗暂只支持扫码登录；酷狗个人每日推荐暂未提供；搜索目前只有第一页（最多 40 首）。
- 26.x 的歌词和播放器界面仍需要 OpenGL；选择 Vulkan 时只能放音乐。
- 完全替换原版主菜单的第三方模组，主菜单入口需另行确认。
- 会访问的外部服务：网易云 / QQ 音乐 / 酷狗接口；一起听歌用的 Firebase 和作者的 Cloudflare 中转；检查更新时访问 GitHub 和该中转。
