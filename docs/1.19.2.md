# Minecraft 1.19.2（Forge 43.x）

构建产物：`DangoMusic-<版本>+1.19.2-forge.jar`，需要 Forge **43.x**。

```bash
cd modern
gradlew :1.19.2-forge:build     # 输出 modern/versions/1.19.2-forge/build/libs/
gradlew :1.19.2-forge:runClient
```

## 实现说明

- 版本差异全部收在 `modern/src/mc1.19.2/McCompat.kt`，入口在 `modern/versions/1.19.2-forge/`。
- 1.19.3 起 Minecraft 才自带 `org.joml`，而共用代码的矩阵运算依赖它，所以这个版本的构建会额外 shade
  并重定位 `joml:1.10.5`（见 `modern/build.gradle.kts`）。
- 原版矩阵类型是 `com.mojang.math.Matrix4f`（与 joml 做列主序互转）；`RenderSystem#setProjectionMatrix`
  只有一个参数（没有 `VertexSorting`）；`Font#drawInBatch` 用 `boolean transparent`；`Screen#render(PoseStack)`。
- 没有 `Minecraft#getFps()`，帧率由 `McCompat` 自己按 1 秒窗口统计。
- `RenderLevelStageEvent` 在 1.19.2 没有 `Stage.AFTER_LEVEL`，入口改用 `RenderLevelLastEvent`。

## 已知差距

主菜单的「正在播放」浮层与全景背景（`McCompat.mainMenuNowPlaying` / `renderMenuBackdrop`）依赖
`GuiGraphics`，1.19.2 暂以空实现代替：主菜单可以打开播放器，但背景为纯色、没有浮层。
